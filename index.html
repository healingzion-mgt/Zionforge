GitHub deployment guide

Keep your project code backed up and ready to deploy.

⌘

Publish your code to GitHub

GitHub stores your project files and keeps a history of your changes.

Open GitHub · Create a repository ↗
  1. Sign in to GitHub

    Open GitHub and sign in to your account.

  2. Create a new repository

    Choose a clear name such as zionforge-first-app. For a private project, choose Private.

  3. Upload your project files

    Open the repository, choose Add file → Upload files, select your project files and commit the changes.

  4. Check the repository

    Make sure index.html and the other project files appear in the repository root.

Tip: Never upload API keys, passwords, or secret environment files to GitHub.

Cloudflare deployment guide

Publish a website from your GitHub repository.

☁

Deploy with Cloudflare Pages

For this first static prototype, Cloudflare Pages can publish the site directly from GitHub.

Open Cloudflare Pages ↗
  1. Sign in to Cloudflare

    Open the Cloudflare dashboard and choose Workers & Pages, then Create.

  2. Connect to GitHub

    Authorise Cloudflare to access the repository you created.

  3. Select your repository

    Choose the ZIONFORGE project repository. For this static version, leave the build command blank and set the output directory to /.

  4. Deploy

    Click Save and Deploy. Cloudflare will provide a public pages.dev address.

  5. Test your live website

    Open the link on your phone and computer. Check all navigation and project screens.

Important: The AI generation endpoint is a Cloudflare Pages Function. Add your AI provider key as a secret named OPENAI_API_KEY in your Pages project settings before using live AI generation.
