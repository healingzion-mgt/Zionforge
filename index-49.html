GO LIVE

Publish your project

From the downloaded zip to a live website, in three steps.

1. Put the files on GitHub

  1. Unzip the download on your phone or computer.
  2. In GitHub, tap New repository. Give it a clear name and choose Private if you prefer.
  3. Tap Add file, then Upload files, choose the project files and tap Commit changes.

Never upload passwords or API keys to GitHub.

2. Publish with Cloudflare Pages

  1. Cloudflare: Workers & Pages, then Create application.
  2. Choose the Pages option (the small link at the bottom), then Import an existing Git repository.
  3. Select your repository and branch main.
  4. Framework preset: None. Build command: empty. Output directory: /. Tap Save and Deploy.

Choose Pages, not Workers. A project with a functions folder will fail as a Worker.

3. Check it on your phone

  1. Open the new .pages.dev address.
  2. Test every button, form and page.
  3. To use your own address, open the project, tap Custom domains and add it.
